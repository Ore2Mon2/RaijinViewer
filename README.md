# Raijin Viewer

日本語 | [English](README.en.md)

フォルダ内の画像を素早く確認できる、軽量な画像ビューアです。
JPG / PNG / WebP / GIF に対応しています。

- 設定・ログなどは **Windows では `RaijinViewer.exe` と同じフォルダ内**に保存されます(`%AppData%` などには何も作りません)。macOS では `~/Library/Application Support/RaijinViewer` に保存されます
- 表示は日本語と英語に対応。OS の言語に合わせて自動で選ばれ(日本語なら日本語、それ以外は英語)、**L キー**でいつでも切り替えられます

## 動作環境

- Windows 11(64bit)
- macOS(Apple Silicon の Mac。macOS 26 で動作確認)

## 使い方

画像ファイルまたはフォルダをウィンドウにドロップします。

### キーボード

| 操作 | 内容 |
|---|---|
| → / ↓、← / ↑ | 次 / 前のファイル |
| Delete | ファイルを削除(ごみ箱へ) |
| Shift + Delete、Ctrl + Z | 削除を元に戻す |
| Enter | 上下のバーを隠す / 表示 |
| Backspace | サムネイルパネルの表示 / 非表示 |
| Home / End | 拡大 / 縮小(1〜4倍) |
| F5、Ctrl + R | フォルダを再読み込み |
| H | 操作リファレンスを表示 |
| V | バージョン情報を表示 |
| O | 最近開いたフォルダの一覧を表示(↑↓で選択、Enter で開く、Esc で閉じる) |
| L | 表示言語を切り替え(日本語 / English) |
| Space | 新しいウィンドウ(別プロセス)を起動 |

### マウス

| 操作 | 内容 |
|---|---|
| ホイール | 前 / 次のファイル |
| 進む / 戻るボタン | 拡大 / 縮小 |
| 右ボタン長押し(等倍時) | ルーペ表示 |
| 右ボタンドラッグ(拡大時) | 表示位置を移動 |
| 左ダブルクリック | ウィンドウを最小化 |
| 右ダブルクリック | 上下のバーを隠す / 表示 |
| 左右ボタン同時押し | サムネイルパネルの表示 / 非表示 |
| 左ボタン + 戻るボタン同時押し | ファイルを削除 |
| 左下のアイコンを右クリック | 最近開いたフォルダの一覧を表示(クリックで開く) |
| サムネイル / 画像をドラッグ | エクスプローラー(Finder)のフォルダへ**コピー** |
| Shift + ドラッグ | エクスプローラー(Finder)のフォルダへ**移動** |
